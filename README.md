# Planificador de Tareas 💜

Aplicación web del Bootcamp de Generation.

---

## 📋 Descripción del Proyecto

El **Planificador de Tareas** permite registrar nuevas actividades indicando su título, descripción, fecha límite de entrega y nivel de prioridad (**Alta**, **Media** o **Baja**), además de visualizar el listado de tareas organizadas por tarjetas con indicadores visuales de estado (**Pendiente** y **Completada**), filtrado lateral y cambio de estado interactivo (*toggle*).

## 🛠️ Tecnologías Utilizadas

- **HTML5** (Estructura semántica)
- **CSS3** (Estilos personalizados )
- **Bootstrap 5.3** ( tarjetas, insignias, formularios y alertas)
- **JavaScript (ES6 & POO)** (Programación orientada a objetos con `TaskManager`, manipulación del DOM, validaciones e interactividad de estados)
- **Git & GitHub** (Control de versiones y despliegue en GitHub Pages)
