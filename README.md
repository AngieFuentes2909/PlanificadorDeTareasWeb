# Planificador de Tareas 💜

Aplicación web del Bootcamp de Generation.

---

## 📋 Descripción del Proyecto

El **Planificador de Tareas** permite registrar nuevas actividades indicando su título, descripción, fecha límite de entrega y nivel de prioridad (**Alta**, **Media** o **Baja**), además de visualizar el listado de tareas organizadas por tarjetas con indicadores visuales de estado (**En progreso**, **Pendiente** y **Completada**).

## 🛠️ Tecnologías Utilizadas

- **HTML5** (Estructura semántica)
- **CSS3** (Estilos personalizados )
- **Bootstrap 5.3** (Sistema de grillas, tarjetas, insignias, formularios y alertas)
- **JavaScript (ES6)** (Manipulación del DOM y validación de formularios)
